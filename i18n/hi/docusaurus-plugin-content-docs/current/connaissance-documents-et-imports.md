# Knowledge, documents और imports

यह पृष्ठ बताता है कि project knowledge कैसे maintain करें और उसे agents व PM Documents के evidence के रूप में कैसे उपयोग करें।

## Document upload करना

1. **Knowledge** खोलें।
2. **Upload** चुनें।
3. file चुनें।
4. category या metadata भरें।
5. upload शुरू करें।
6. **Indexed** status की प्रतीक्षा करें।

## Approved source से import

1. **Knowledge** खोलें।
2. import action चुनें।
3. available source चुनें।
4. import शुरू करें।
5. import history देखें।
6. document को **Indexed** होने के बाद ही उपयोग करें।

## Status

| Status | अर्थ | कार्रवाई |
| --- | --- | --- |
| Indexed | search और agents के लिए ready | उपयोग करें |
| Ingesting | processing चल रही है | प्रतीक्षा और refresh |
| Failed | processing failed | format/source जाँचें |
| Not visible | गलत project, filter या role | context जाँचें |

## Search

Business term, question या document name से search करें। उपयोग से पहले snippet, citation, source label, source system और freshness पढ़ें।
