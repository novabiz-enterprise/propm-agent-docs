# Dashboard

Dashboard active project का सार दिखाता है: activity, knowledge, agents, PM Documents, signals, actions और shortcuts।

## शुरू करने से पहले

- आप sign in हैं।
- active project चुना गया है।
- आपकी role project देखने की अनुमति देती है।

## Dashboard पढ़ना

1. **Dashboard** खोलें।
2. top bar में active project जाँचें।
3. documents, runs, PM Documents, signals और actions की cards पढ़ें।
4. recent activity देखें।
5. **Workspace**, **Knowledge**, **Agents**, **PM Docs** या **AI Log** shortcuts खोलें।

## Empty states

| स्थिति | अर्थ | कार्रवाई |
| --- | --- | --- |
| No active project | project context नहीं है | project चुनें |
| No project available | account को project access नहीं है | Project Owner से संपर्क करें |
| Access denied | role पर्याप्त नहीं | सही role माँगें |
| पुराने numbers | processing चल रही है | refresh करें या प्रतीक्षा करें |
