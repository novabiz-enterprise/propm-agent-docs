# Agents

Agents active project context में काम करते हैं और evidence वाली structured outputs बना सकते हैं।

## Standard agents

| आवश्यकता | Agent |
| --- | --- |
| cross-project analysis | Orchestrator |
| policies और approvals | Governance |
| scope और requirements | Scope |
| schedule और dependencies | Schedule |
| budget और costs | Finance |
| stakeholders और communication | Stakeholders |
| capacity और resources | Resources |
| risks और issues | Risk |

## Run शुरू करना

1. **Agents** खोलें।
2. active project जाँचें।
3. agent चुनें।
4. objective और context के साथ precise prompt लिखें।
5. यदि उपलब्ध हो तो documents जोड़ें।
6. run शुरू करें।
7. answer, citations, freshness और confidence पढ़ें।
8. audit के लिए [AI Log](./journal-ia.md) खोलें।

## Custom agents

सही role होने पर custom agent बनाएँ। नाम, purpose, project scope या `All projects` चुनें, save करें और simple prompt से test करें।

## Notes

Agent answer final PM Document नहीं है। Chat history browser-local हो सकती है।
