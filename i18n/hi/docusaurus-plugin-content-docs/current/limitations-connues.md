# Known limitations

## User limits

| Topic | Limit | Best practice |
| --- | --- | --- |
| Chat history | browser-local हो सकती है | shared traceability के लिए PM Documents और AI Log उपयोग करें |
| Active project | pages selected project पर depend करती हैं | top bar जाँचें |
| `All projects` | all tenant projects access नहीं देता | actual access verify करें |
| Agent answer | final document नहीं है | review करें और जरूरत पर PM Document बनाएँ |
| Confidence | approval नहीं है | evidence और freshness verify करें |

## Integrations

Visible connector हमेशा usable नहीं होता। Platform definition, project binding, policy, role, health और live mode सही होने चाहिए।

## Azure administration

Deployment में selected provider किसी run के actual provider का proof नहीं है। **Refresh Marketplace plan** केवल information sync करता है।
