# Azure और Entra administration

यह पृष्ठ Azure और tenant administrators के लिए है।

## Deploy करना

1. Azure Marketplace में ProPM Agent offer खोलें।
2. plan, subscription, region और resource group चुनें।
3. wizard के required fields भरें।
4. initial AI provider family चुनें।
5. deployment शुरू करें।
6. published URL खोलें।
7. Entra access और first administrators final करें।
