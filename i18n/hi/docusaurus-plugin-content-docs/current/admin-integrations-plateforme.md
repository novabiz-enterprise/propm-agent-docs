# Platform integrations

Integrations platform level पर define होती हैं और project binding के बाद usable बनती हैं।

## चार levels

| Level | सवाल |
| --- | --- |
| Platform | integration defined और validated है? |
| Project | active project से bound है? |
| Governance | policy action allow करती है? |
| Execution | health, role और live mode पर्याप्त हैं? |

## Integration define करना

1. **Platform Administration** खोलें।
2. **Platform Integrations** खोलें।
3. connector या ingestion provider चुनें।
4. definition create/open करें।
5. save और validate करें।
6. validation history देखें।

## Project binding

1. project खोलें।
2. project integrations खोलें।
3. validated integration चुनें।
4. **Bind to project** करें।
5. readiness और health जाँचें।
