# AI Log

AI Log दिखाता है कि execution में वास्तव में क्या हुआ: run, status, time, user, project, effective AI provider और support IDs।

## Run ढूँढना

1. **AI Log** खोलें।
2. **Runs** चुनें।
3. project, agent, status या period से filter करें।
4. run खोलें।
5. status, time, effective provider और artifact links देखें।

## Effective provider verify करना

1. run details खोलें।
2. **Effective AI Provider** खोजें।
3. expected provider से तुलना करें।
4. difference note करें।
5. repeated issue पर [AI provider](./admin-fournisseur-ia.md) खोलें।

## Support

Run ID, Trace ID, Artifact ID या Action ID दिखाई दें तो collect करें। sensitive payload copy न करें।
