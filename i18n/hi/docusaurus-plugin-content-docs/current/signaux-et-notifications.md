# Signals और notifications

Signals risks, blockers, missing evidence या opportunities पर ध्यान दिलाते हैं।

## Signal पढ़ना

1. **Signals**, **Inbox** या Workspace signal area खोलें।
2. severity, status, mode और date देखें।
3. details खोलें।
4. evidence और recommendations पढ़ें।
5. decide करें: handle, snooze, dismiss, draft या action।

## Actions

| Action | प्रभाव |
| --- | --- |
| Refresh | signals recalculation या reload |
| Generate digest draft | digest draft बनाता है |
| Create draft | usable draft बनाता है |
| Snooze 24h | temporary delay |
| Dismiss | signal close |

## Notification center

bell खोलें, entries पढ़ें, links follow करें, mark all read करें या local list clear करें।
