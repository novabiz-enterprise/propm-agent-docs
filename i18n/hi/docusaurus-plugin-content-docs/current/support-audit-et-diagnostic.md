# Support, audit और diagnostics

यह पृष्ठ incident के समय useful information बताता है।

## NovaBiz contact

NovaBiz support के लिए:

- Email: [support@navabiz.pro](mailto:support@navabiz.pro)
- Address: NovaBiz, 131 Continental Dr, Suite 305, Newark, DE 19713, United States

## क्या दें

| Information | Example |
| --- | --- |
| Page URL | error वाली page |
| Active project | project name |
| User | account या group, password नहीं |
| Time | date, time, timezone |
| Action | upload, run, publish, approve |
| Message | exact text या masked screenshot |
| IDs | Run ID, Trace ID, Action ID यदि visible हों |

## कभी न दें

- passwords, secrets, tokens या keys.
- sensitive customer data वाले full payloads.
- unmasked customer data.

## Quick diagnostics

| Symptom | पहली जाँच |
| --- | --- |
| login fail | account, tenant, URL |
| no project | membership और role |
| document not indexed | Knowledge status |
| agent no answer | AI Log में run |
| action pending | approval, policy, connector |
| license blocked | remaining seats |
