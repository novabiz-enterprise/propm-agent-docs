# AI प्रदाता

![AI provider workflow](/img/annotated/hi/ai-provider-annotated.svg)

यह पृष्ठ platform level पर AI provider administration समझाता है।

## Actions

| Action | उद्देश्य |
| --- | --- |
| Save | configuration save करना |
| Validate | consistency check करना |
| Test | functional test चलाना |
| Activate | provider को runs के लिए active करना |

## Configure करना

1. **Platform Administration** खोलें।
2. **AI Provider Settings** खोलें।
3. provider type चुनें।
4. UI fields भरें।
5. **Save** चुनें।
6. **Validate** चलाएँ।
7. **Test** चलाएँ।
8. **Activate** चुनें।
9. real run को [AI Log](./journal-ia.md) में verify करें।

## Important

Secrets secure administration tools में रहें। run का effective provider AI Log में confirm होता है।
