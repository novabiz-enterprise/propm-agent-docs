# Active project और project creation

Active project तय करता है कि Knowledge, Agents, PM Documents, Signals और AI Log में कौन सा data दिखेगा।

## Project चुनना

1. top bar में project switcher खोलें।
2. project खोजें।
3. project चुनें।
4. top bar में नाम सत्यापित करें।
5. Dashboard खोलकर data जाँचें।

## Project बनाना

1. **Projects** खोलें।
2. **Create project** चुनें, यदि उपलब्ध है।
3. नाम, description और required settings भरें।
4. data language चुनें, यदि field दिखता है।
5. Save करें।
6. पुष्टि करें कि project selectable है।

## मुख्य concepts

| Concept | अर्थ |
| --- | --- |
| Active project | वर्तमान कार्य context |
| `All projects` | वही projects जिन तक उसी account की पहले से पहुँच है |
| Local project memory | browser preference, platform-wide setting नहीं |

## समस्याएँ

| समस्या | कारण | कार्रवाई |
| --- | --- | --- |
| button नहीं है | role पर्याप्त नहीं | Project Owner से कहें |
| project नहीं दिखता | membership नहीं है | access माँगें |
| data गलत है | गलत active project | project बदलें और reload करें |
