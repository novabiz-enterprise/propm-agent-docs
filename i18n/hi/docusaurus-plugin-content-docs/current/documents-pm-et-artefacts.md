# PM Documents और artifacts

यह पृष्ठ run से reviewed PM Document तक document flow समझाता है।

## Lifecycle

**Run → structured output → artifact → version → PM Document → Download / Publish / Add to knowledge**.

| Term | अर्थ |
| --- | --- |
| Structured output | agent result जिसे review चाहिए |
| Artifact | run या review से governed object |
| Version | diff के साथ historical state |
| PM Document | reviewed और versioned deliverable |

## Document review

1. **PM Docs** या **Reports & artifacts** खोलें।
2. active project जाँचें।
3. status, type या date से filter करें।
4. document खोलें।
5. content, evidence, diff और lineage देखें।
6. permission हो तो changes save करें।
7. review के बाद **Download**, **Publish** या **Add to knowledge** करें।

## Actions

| Action | प्रभाव |
| --- | --- |
| Download | local copy बनाता है |
| Publish | governed destination पर भेजता है |
| Add to knowledge | reviewed document को project knowledge में जोड़ता है |
