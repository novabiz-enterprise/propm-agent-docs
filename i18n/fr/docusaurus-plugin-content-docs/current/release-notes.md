## Objectif

Cette page suit les évolutions de la documentation utilisateur ProPM Agent. Elle ne remplace pas les notes de version produit ou les communications contractuelles.

## 2026-05-10 — Refonte documentation utilisateur Azure

| Domaine | Changement documentaire |
| --- | --- |
| Navigation | Réorganisation par parcours : prise en main, usage, gouvernance, administration projet, Portfolio, administration Azure, sécurité, support |
| Source française | `i18n/fr/docusaurus-plugin-content-docs/current` devient la source française maintenue |
| Recherche | Suppression de `docs-fr` de l’index de recherche pour éviter les doublons divergents |
| Utilisateur final | Ajout des pages Tableau de bord, Projet actif, Connaissance, Agents, Documents PM, Journal IA, Signaux, Actions |
| Administration Azure | Ajout des pages Azure/Entra, Fournisseur IA, Intégrations plateforme, Licences/plans/mises à jour |
| Support | Ajout d’une page Support, audit et diagnostic et refonte de la FAQ |
| Sécurité | Ajout de Sécurité et conformité et Limitations connues |
| Glossaire | Harmonisation des termes clés : Projet actif, All projects, Rattachement, Document PM, Fournisseur IA effectif, Entitlement |

## Points de vigilance éditoriaux

- Les pages `de`, `es` et `hi` créées pour les nouvelles routes contiennent des contenus minimaux à compléter lors d’une passe de localisation.
- Les captures doivent être revues à chaque changement majeur d’interface.
- Les pages legacy restent conservées lorsqu’un slug public existait déjà.
