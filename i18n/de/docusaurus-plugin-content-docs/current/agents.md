# Agenten

Agenten arbeiten im aktiven Projektkontext und können strukturierte Ausgaben mit Nachweisen erzeugen.

## Standardagenten

| Bedarf | Agent |
| --- | --- |
| Übergreifende Analyse | Orchestrator |
| Richtlinien und Freigaben | Governance |
| Umfang und Anforderungen | Scope |
| Planung und Abhängigkeiten | Schedule |
| Budget und Kosten | Finance |
| Stakeholder und Kommunikation | Stakeholders |
| Kapazität und Ressourcen | Resources |
| Risiken und Probleme | Risk |

## Run starten

1. Öffnen Sie **Agents**.
2. Prüfen Sie das aktive Projekt.
3. Wählen Sie den Agenten.
4. Schreiben Sie eine präzise Anfrage mit Ziel und Kontext.
5. Fügen Sie relevante Dokumente hinzu, falls möglich.
6. Starten Sie den Run.
7. Lesen Sie Antwort, Zitate, Frische und Vertrauen.
8. Öffnen Sie bei Bedarf das [KI-Journal](./journal-ia.md).

## Eigene Agenten

Erstellen Sie einen eigenen Agenten nur mit passender Rolle. Wählen Sie Name, Zweck, Projektbereich oder `All projects`, speichern Sie und testen Sie mit einer einfachen Anfrage.

## Hinweise

Eine Agentenantwort ist kein finales PM-Dokument. Chatverlauf kann browserlokal sein.
