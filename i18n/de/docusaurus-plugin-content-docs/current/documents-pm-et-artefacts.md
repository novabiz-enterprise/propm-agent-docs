# PM-Dokumente und Artefakte

Diese Seite beschreibt den Dokumentenfluss von einem Run bis zu einem geprüften PM-Dokument.

## Lebenszyklus

**Run → strukturierte Ausgabe → Artefakt → Version → PM-Dokument → Download / Publish / Add to knowledge**.

| Begriff | Bedeutung |
| --- | --- |
| Strukturierte Ausgabe | Agentenergebnis, noch zu prüfen |
| Artefakt | Governed Objekt aus Run oder Review |
| Version | Historisierter Zustand mit Diff |
| PM-Dokument | Geprüfter, versionierter Projektliefergegenstand |

## Dokument prüfen

1. Öffnen Sie **PM Docs** oder **Reports & artifacts**.
2. Prüfen Sie das aktive Projekt.
3. Filtern Sie nach Status, Typ oder Datum.
4. Öffnen Sie das Dokument.
5. Prüfen Sie Inhalt, Nachweise, Diff und Lineage.
6. Speichern Sie Änderungen, falls erlaubt.
7. Verwenden Sie **Download**, **Publish** oder **Add to knowledge** nach Review.

## Aktionen

| Aktion | Wirkung |
| --- | --- |
| Download | Lokale Kopie erzeugen |
| Publish | An eine gesteuerte Zielablage veröffentlichen |
| Add to knowledge | Geprüftes Dokument in Projektwissen aufnehmen |
