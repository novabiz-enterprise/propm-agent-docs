# KI-Journal

Das KI-Journal zeigt, was bei einer Ausführung tatsächlich passiert ist: Run, Status, Zeit, Nutzer, Projekt, effektiver KI-Anbieter und Support-IDs.

## Run finden

1. Öffnen Sie **AI Log**.
2. Wechseln Sie zu **Runs**.
3. Filtern Sie nach Projekt, Agent, Status oder Zeitraum.
4. Öffnen Sie den Run.
5. Prüfen Sie Status, Zeit, effektiven Anbieter und Links zu Artefakten.

## Effektiven Anbieter prüfen

1. Öffnen Sie die Run-Details.
2. Suchen Sie **Effective AI Provider**.
3. Vergleichen Sie ihn mit dem erwarteten Anbieter.
4. Notieren Sie Abweichungen.
5. Bei wiederholter Abweichung öffnen Sie [KI-Anbieter](./admin-fournisseur-ia.md).

## Supporthinweis

Sammeln Sie Run ID, Trace ID, Artifact ID oder Action ID, wenn sichtbar. Kopieren Sie keine sensiblen Payloads.
