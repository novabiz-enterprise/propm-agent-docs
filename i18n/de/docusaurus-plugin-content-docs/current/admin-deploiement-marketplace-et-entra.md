# Azure- und Entra-Administration

Diese Seite richtet sich an Azure- und Tenant-Administratoren.

## Bereitstellen

1. Öffnen Sie das ProPM-Agent-Angebot in Azure Marketplace.
2. Wählen Sie Plan, Abonnement, Region und Ressourcengruppe.
3. Geben Sie die im Assistenten verlangten Werte ein.
4. Wählen Sie die initiale KI-Anbieterfamilie.
5. Starten Sie die Bereitstellung.
6. Öffnen Sie die veröffentlichte URL.
7. Schließen Sie Entra-Zugriff und erste Administratoren ab.
