# Dashboard

Das Dashboard fasst den aktiven Projektkontext zusammen: Aktivität, Wissen, Agenten, PM-Dokumente, Signale, Aktionen und Schnellzugriffe.

## Voraussetzungen

- Sie sind angemeldet.
- Ein aktives Projekt ist ausgewählt.
- Ihre Rolle erlaubt den Zugriff.

## Dashboard lesen

1. Öffnen Sie **Dashboard**.
2. Prüfen Sie das aktive Projekt in der oberen Leiste.
3. Lesen Sie Karten für Dokumente, Runs, PM-Dokumente, Signale und Aktionen.
4. Prüfen Sie die jüngste Aktivität.
5. Öffnen Sie den passenden Schnellzugriff: **Workspace**, **Knowledge**, **Agents**, **PM Docs** oder **AI Log**.

## Leere Zustände

| Zustand | Bedeutung | Aktion |
| --- | --- | --- |
| Kein aktives Projekt | Seiten haben keinen Projektkontext | Projekt auswählen |
| Kein Projekt verfügbar | Ihr Konto hat keinen Projektzugriff | Project Owner kontaktieren |
| Zugriff verweigert | Rolle reicht nicht aus | Rolle prüfen lassen |
| Veraltete Zahlen | Verarbeitung läuft noch | Seite aktualisieren oder später erneut prüfen |
