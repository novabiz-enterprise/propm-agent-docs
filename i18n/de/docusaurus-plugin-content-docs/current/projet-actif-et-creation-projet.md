# Aktives Projekt und Projekterstellung

Das aktive Projekt bestimmt, welche Daten in Knowledge, Agents, PM Documents, Signals und AI Log sichtbar sind.

## Projekt auswählen

1. Öffnen Sie den Projektumschalter in der oberen Leiste.
2. Suchen Sie das gewünschte Projekt.
3. Wählen Sie es aus.
4. Prüfen Sie den Projektnamen in der oberen Leiste.
5. Öffnen Sie das Dashboard und bestätigen Sie die Daten.

## Projekt erstellen

1. Öffnen Sie **Projects**.
2. Wählen Sie **Create project**, falls verfügbar.
3. Geben Sie Name, Beschreibung und erforderliche Einstellungen ein.
4. Wählen Sie die Standardsprache der Projektdaten, falls angeboten.
5. Speichern Sie.
6. Prüfen Sie, ob das Projekt auswählbar ist.

## Wichtige Begriffe

| Begriff | Bedeutung |
| --- | --- |
| Aktives Projekt | Aktueller Arbeitskontext |
| `All projects` | Nur Projekte, auf die dasselbe Konto bereits Zugriff hat |
| Lokal gemerktes Projekt | Browserpräferenz, nicht globale Plattformregel |

## Häufige Probleme

| Symptom | Ursache | Aktion |
| --- | --- | --- |
| Schaltfläche fehlt | Rolle reicht nicht aus | Project Owner kontaktieren |
| Projekt fehlt | Sie sind kein Mitglied | Hinzufügen lassen |
| Daten passen nicht | Falsches aktives Projekt | Projekt wechseln und neu laden |
