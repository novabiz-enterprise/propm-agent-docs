# Wissen, Dokumente und Importe

Diese Seite erklärt, wie Sie Projektwissen pflegen und als Nachweis für Agenten und PM-Dokumente nutzen.

## Dokument hochladen

1. Öffnen Sie **Knowledge**.
2. Wählen Sie **Upload**.
3. Wählen Sie die Datei.
4. Ergänzen Sie Kategorie oder Metadaten.
5. Starten Sie den Upload.
6. Warten Sie auf den Status **Indexed**.

## Aus genehmigter Quelle importieren

1. Öffnen Sie **Knowledge**.
2. Wählen Sie die Importaktion.
3. Wählen Sie die verfügbare Quelle.
4. Starten Sie den Import.
5. Prüfen Sie den Importverlauf.
6. Verwenden Sie Dokumente erst nach **Indexed**.

## Status

| Status | Bedeutung | Aktion |
| --- | --- | --- |
| Indexed | Bereit für Suche und Agenten | Verwenden |
| Ingesting | Verarbeitung läuft | Warten und aktualisieren |
| Failed | Verarbeitung fehlgeschlagen | Format/Quelle prüfen |
| Nicht sichtbar | Falsches Projekt, Filter oder Rolle | Projekt und Filter prüfen |

## Suche

Suchen Sie nach Fachbegriffen, Dokumentnamen oder Fragen. Lesen Sie Snippet, Zitat, Source Label, Source System und Frische, bevor Sie eine Aussage verwenden.
