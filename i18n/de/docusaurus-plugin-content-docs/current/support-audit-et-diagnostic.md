# Support, Audit und Diagnose

Diese Seite erklärt, welche Informationen bei einem Incident nützlich sind.

## NovaBiz Kontakt

Für den NovaBiz Support:

- E-Mail: [support@navabiz.pro](mailto:support@navabiz.pro)
- Adresse: NovaBiz, 131 Continental Dr, Suite 305, Newark, DE 19713, United States

## Zu liefern

| Information | Beispiel |
| --- | --- |
| Seiten-URL | Seite beim Fehler |
| Aktives Projekt | Projektname |
| Nutzer | Konto oder Gruppe, kein Passwort |
| Zeitpunkt | Datum, Uhrzeit, Zeitzone |
| Aktion | Upload, Run, Publish, Approve |
| Meldung | Exakter Text oder maskierter Screenshot |
| IDs | Run ID, Trace ID, Action ID falls sichtbar |

## Niemals liefern

- Passwörter, Secrets, Tokens oder Schlüssel.
- Vollständige sensible Payloads.
- Unmaskierte Kundendaten.

## Schnelldiagnose

| Symptom | Erste Prüfung |
| --- | --- |
| Anmeldung scheitert | Konto, Tenant, URL |
| Kein Projekt | Mitgliedschaft und Rolle |
| Dokument nicht indexiert | Status in Knowledge |
| Agent antwortet nicht | Run im KI-Journal |
| Aktion wartet | Freigabe, Richtlinie, Connector |
| Lizenz blockiert | Verbleibende Seats |
