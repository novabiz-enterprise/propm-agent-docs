# KI-Anbieter

Diese Seite erklärt die Administration des KI-Anbieters auf Plattformebene.

## Aktionen

| Aktion | Zweck |
| --- | --- |
| Save | Konfiguration speichern |
| Validate | Kohärenz prüfen |
| Test | Funktionalen Test ausführen |
| Activate | Anbieter für Runs aktivieren |

## Konfiguration

1. Öffnen Sie **Platform Administration**.
2. Öffnen Sie **AI Provider Settings**.
3. Wählen Sie den Anbietertyp.
4. Füllen Sie die Felder der Oberfläche aus.
5. Wählen Sie **Save**.
6. Führen Sie **Validate** aus.
7. Führen Sie **Test** aus.
8. Wählen Sie **Activate**.
9. Prüfen Sie einen echten Run im [KI-Journal](./journal-ia.md).

## Wichtig

Secrets bleiben in sicheren Administrationswerkzeugen. Der effektive Anbieter eines Runs ist im KI-Journal maßgeblich.
