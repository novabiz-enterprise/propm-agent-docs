# Signale und Benachrichtigungen

Signale lenken Aufmerksamkeit auf Risiken, Blocker, fehlende Nachweise oder Aktionen.

## Signal lesen

1. Öffnen Sie **Signals**, **Inbox** oder den Signalbereich im Workspace.
2. Prüfen Sie Schweregrad, Status, Modus und Datum.
3. Öffnen Sie die Details.
4. Lesen Sie Nachweise und Empfehlungen.
5. Entscheiden Sie: behandeln, zurückstellen, schließen, Entwurf oder Aktion erstellen.

## Aktionen

| Aktion | Wirkung |
| --- | --- |
| Refresh | Signale neu laden oder berechnen |
| Generate digest draft | Digest-Entwurf vorbereiten |
| Create draft | Verwertbaren Entwurf erzeugen |
| Snooze 24h | Vorübergehend zurückstellen |
| Dismiss | Signal schließen |

## Benachrichtigungen

Öffnen Sie die Glocke, lesen Sie Einträge, folgen Sie Links, markieren Sie alles als gelesen oder löschen Sie die lokale Liste, wenn sie nicht mehr benötigt wird.
