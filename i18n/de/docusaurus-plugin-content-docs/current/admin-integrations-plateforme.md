# Plattformintegrationen

Integrationen werden auf Plattformebene definiert und auf Projektebene nutzbar gemacht.

## Vier Ebenen

| Ebene | Frage |
| --- | --- |
| Plattform | Ist die Integration definiert und validiert? |
| Projekt | Ist sie an das aktive Projekt gebunden? |
| Governance | Erlaubt die Richtlinie die Aktion? |
| Ausführung | Sind Gesundheit, Rolle und Live-Modus ausreichend? |

## Integration definieren

1. Öffnen Sie **Platform Administration**.
2. Öffnen Sie **Platform Integrations**.
3. Wählen Sie Connector oder Ingestion Provider.
4. Erstellen oder öffnen Sie die Definition.
5. Speichern und validieren Sie.
6. Prüfen Sie den Validierungsverlauf.

## Projektbindung

1. Öffnen Sie das Projekt.
2. Öffnen Sie Projektintegrationen.
3. Wählen Sie die validierte Integration.
4. Nutzen Sie **Bind to project**.
5. Prüfen Sie Readiness und Health.
