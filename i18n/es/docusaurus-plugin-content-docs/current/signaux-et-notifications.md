# Señales y notificaciones

Las señales llaman la atención sobre riesgos, bloqueos, falta de evidencias u oportunidades.

## Leer una señal

1. Abra **Signals**, **Inbox** o el área de señales en Workspace.
2. Revise severidad, estado, modo y fecha.
3. Abra los detalles.
4. Lea evidencias y recomendaciones.
5. Decida: tratar, posponer, cerrar, crear borrador o acción.

## Acciones

| Acción | Efecto |
| --- | --- |
| Refresh | Recalcular o recargar señales |
| Generate digest draft | Preparar un digest |
| Create draft | Crear un borrador utilizable |
| Snooze 24h | Posponer temporalmente |
| Dismiss | Cerrar la señal |

## Centro de notificaciones

Abra la campana, lea entradas, siga enlaces, marque todo como leído o limpie la lista local si ya no es necesaria.
