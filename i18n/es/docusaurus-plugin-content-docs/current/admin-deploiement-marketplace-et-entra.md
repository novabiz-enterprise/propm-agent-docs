# Administración Azure y Entra

Esta página es para administradores Azure y tenant.

## Desplegar

1. Abra la oferta ProPM Agent en Azure Marketplace.
2. Elija plan, suscripción, región y grupo de recursos.
3. Complete los campos del asistente.
4. Elija la familia inicial de proveedor IA.
5. Inicie el despliegue.
6. Abra la URL publicada.
7. Finalice acceso Entra y primeros administradores.
