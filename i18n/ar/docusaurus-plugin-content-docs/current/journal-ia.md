# سجل الذكاء الاصطناعي

يعرض سجل الذكاء الاصطناعي ما حدث فعلا أثناء تنفيذ: run، والحالة، والوقت، والمستخدم، والمشروع، ومزود الذكاء الاصطناعي الفعلي، ومعرفات الدعم.

## العثور على run

1. افتح **AI Log**.
2. اختر **Runs**.
3. رشح حسب المشروع، أو الوكيل، أو الحالة، أو الفترة.
4. افتح run.
5. تحقق من الحالة، والوقت، والمزود الفعلي، والروابط إلى الآثار.

## المزود الفعلي

1. افتح تفاصيل run.
2. ابحث عن **Effective AI Provider**.
3. قارنه بالمزود المتوقع.
4. دوّن أي اختلاف.
5. إذا تكرر ذلك، فافتح [مزود الذكاء الاصطناعي](./admin-fournisseur-ia.md).

## الدعم

اجمع Run ID، وTrace ID، وArtifact ID، أو Action ID إذا ظهرت. لا تنسخ payloads حساسة.
