# مزود الذكاء الاصطناعي

![تدفق مزود الذكاء الاصطناعي](/img/annotated/ar/ai-provider-annotated.svg)

تشرح هذه الصفحة إدارة مزود الذكاء الاصطناعي على مستوى المنصة.

## الإجراءات

| الإجراء | الغرض |
| --- | --- |
| Save | حفظ التكوين |
| Validate | التحقق من الاتساق |
| Test | تنفيذ اختبار وظيفي |
| Activate | تفعيل المزود لعمليات التشغيل |

## التكوين

1. افتح **Platform Administration**.
2. افتح **AI Provider Settings**.
3. اختر نوع المزود.
4. أكمل حقول الواجهة.
5. اختر **Save**.
6. نفذ **Validate**.
7. نفذ **Test**.
8. اختر **Activate**.
9. تحقق من تشغيل حقيقي في [سجل الذكاء الاصطناعي](./journal-ia.md).

## مهم

تبقى secrets في أدوات إدارة آمنة. يتم تأكيد مزود عملية التشغيل الفعلي في سجل الذكاء الاصطناعي.
