## تمت إعادة تنظيم هذه الصفحة

يتم الاحتفاظ بعنوان URL هذا كصفحة توجيه حتى لا تنكسر الروابط الموجودة نحو **المحفظة والإدارة التقنية**.

أصبح المحتوى الآن مقسما إلى ثلاثة أقسام إدارية أوضح.

| الحاجة | الانتقال إلى |
| --- | --- |
| مقارنة المشاريع، وتكوين إشارات المحفظة، وقراءة المجموعات، وoutliers، وdrill-downs المشاريع | [المحفظة](./portfolio.md) |
| تكوين مزودي الذكاء الاصطناعي، والتحقق من readiness، وفهم تكاملات المنصة، وbindings، وhealth، والأسباب التقنية للحظر | [مزودو الذكاء الاصطناعي وتكاملات المنصة](./ai-providers-platform-integrations.md) |

## قاعدة المنتج بخصوص خطط Marketplace

تعرض كل خطط Marketplace وظائف المنتج نفسها. لا تتغير إلا سعة التراخيص المطلوبة.

إذا كان مستخدم محظورا، فراجع التراخيص المتبقية، والأدوار، والوصول إلى المشروع، وbindings، وpolicy، والتكوين، أو health. لا تفسر الخطة كمستوى وظيفي.

## ترتيب القراءة الموصى به

1. ابدأ بـ [المحفظة](./portfolio.md) إذا كان السؤال يتعلق بمقارنة المشاريع.
2. تابع إلى [مزودو الذكاء الاصطناعي وتكاملات المنصة](./ai-providers-platform-integrations.md) إذا كان السؤال يتعلق بالجاهزية التقنية، أو المزودين، أو الموصلات، أو bindings.
3. استخدم [خطة المستأجر والمستخدمون المرخصون وتحديثات التطبيق](./seats-management-app-updates.md) إذا كان السؤال يتعلق بتخصيص الوصول، أو تراخيص المستأجر، أو التراخيص التكميلية، أو تحديث تثبيت موجود.
