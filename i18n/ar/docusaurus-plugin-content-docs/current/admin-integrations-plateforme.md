# تكاملات المنصة

تعرّف التكاملات في المنصة وتصبح قابلة للاستخدام عند ربطها بالمشاريع.

## أربعة مستويات

| المستوى | السؤال |
| --- | --- |
| المنصة | هل تم تعريف التكامل والتحقق منه؟ |
| المشروع | هل هو مرتبط بالمشروع النشط؟ |
| الحوكمة | هل تسمح السياسة بالإجراء؟ |
| التنفيذ | هل تكفي الصحة والدور وlive mode؟ |

## تعريف تكامل

1. افتح **Platform Administration**.
2. افتح **Platform Integrations**.
3. اختر connector أو ingestion provider.
4. أنشئ التعريف أو افتحه.
5. احفظ وتحقق.
6. راجع سجل التحقق.

## الربط بمشروع

1. افتح المشروع.
2. افتح تكاملات المشروع.
3. اختر التكامل الذي تم التحقق منه.
4. استخدم **Bind to project**.
5. راجع readiness وhealth.
