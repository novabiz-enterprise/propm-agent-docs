# المعرفة والوثائق وعمليات الاستيراد

تشرح هذه الصفحة كيفية الحفاظ على معرفة المشروع واستخدامها كدليل للوكلاء ومستندات PM.

## رفع وثيقة

1. افتح **Knowledge**.
2. اختر **Upload**.
3. اختر الملف.
4. أكمل الفئة أو البيانات الوصفية.
5. ابدأ الرفع.
6. انتظر الحالة **Indexed**.

## الاستيراد من مصدر معتمد

1. افتح **Knowledge**.
2. اختر إجراء الاستيراد.
3. اختر المصدر المتاح.
4. ابدأ الاستيراد.
5. راجع السجل.
6. استخدم الوثائق فقط عندما تكون **Indexed**.

## الحالات

| الحالة | المعنى | الإجراء |
| --- | --- | --- |
| Indexed | جاهز للبحث والوكلاء | استخدام |
| Ingesting | قيد المعالجة | الانتظار والتحديث |
| Failed | خطأ في المعالجة | مراجعة التنسيق أو المصدر |
| غير مرئي | مشروع أو عامل تصفية أو دور غير صحيح | التحقق من السياق |

## البحث

ابحث عن مصطلحات الأعمال أو الأسئلة أو الوثائق. اقرأ snippet والاقتباس و source label و source system والحداثة قبل إعادة استخدام أي تأكيد.
