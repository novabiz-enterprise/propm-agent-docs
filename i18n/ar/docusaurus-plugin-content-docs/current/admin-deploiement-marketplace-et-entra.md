# إدارة Azure وEntra

هذه الصفحة مخصصة لمسؤولي Azure والمستأجر.

## النشر

1. افتح عرض ProPM Agent في Azure Marketplace.
2. اختر الخطة والاشتراك والمنطقة ومجموعة الموارد.
3. أكمل حقول المعالج.
4. اختر عائلة مزود الذكاء الاصطناعي الأولية.
5. ابدأ النشر.
6. افتح عنوان URL المنشور.
7. أكمل وصول Entra وأول المسؤولين.
