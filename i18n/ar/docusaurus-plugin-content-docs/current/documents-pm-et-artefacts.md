# مستندات PM والآثار

تصف هذه الصفحة التدفق المستندي من run إلى مستند PM تمت مراجعته.

## دورة الحياة

**Run → مخرج منظم → أثر → إصدار → مستند PM → Download / Publish / Add to knowledge**.

| المصطلح | المعنى |
| --- | --- |
| المخرج المنظم | نتيجة وكيل لم تتم مراجعتها بعد |
| الأثر | كائن محكوم آت من run أو مراجعة |
| الإصدار | حالة تاريخية مع diff |
| مستند PM | تسليمة تمت مراجعتها وإدارتها بالإصدارات |

## مراجعة مستند

1. افتح **PM Docs** أو **Reports & artifacts**.
2. تحقق من المشروع النشط.
3. رشح حسب الحالة، أو النوع، أو التاريخ.
4. افتح المستند.
5. راجع المحتوى، والدليل، وdiff، وlineage.
6. احفظ التغييرات إذا كان ذلك مسموحا.
7. استخدم **Download** أو **Publish** أو **Add to knowledge** بعد المراجعة.

## الإجراءات

| الإجراء | الأثر |
| --- | --- |
| Download | إنشاء نسخة محلية |
| Publish | النشر إلى وجهة محكومة |
| Add to knowledge | إضافة المستند الذي تمت مراجعته إلى المعرفة |
