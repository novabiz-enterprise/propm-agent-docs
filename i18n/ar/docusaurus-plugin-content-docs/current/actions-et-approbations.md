# الإجراءات والموافقات

يمكن أن ينشأ إجراء محكوم من إشارة أو مستند أو تدفق موصل، وقد يتطلب موافقة.

## اقتراح إجراء

1. افتح الإشارة أو مستند PM أو الصفحة التي تقترح الإجراء.
2. حدد الإجراء، مثل النشر في SharePoint أو إنشاء ticket Jira.
3. راجع المحتوى والوجهة والتبرير.
4. أرسل الإجراء.
5. تحقق من الحالة.

## الموافقة أو الرفض

1. افتح **Actions & approvals**.
2. صفّ الإجراءات المعلقة.
3. افتح التفاصيل.
4. راجع الأدلة والوجهة والأثر ومقدم الطلب.
5. اختر **Approve** أو **Reject**.

## Approved ليست executed

تعني **Approved** أنه تم التفويض. وتعني **Executed** أن التنفيذ تم فعلا. تتطلب الإجراءات الخارجية موصلا، وbinding للمشروع، وpolicy، ودورا، وحالة صحية، وإذا انطبق الأمر، وضع live.

## العوائق

| العائق | المعنى |
| --- | --- |
| دور غير كاف | لا يمكنه الاقتراح أو الموافقة |
| require approval | الموافقة إلزامية |
| deny | تمنع policy هذا الإجراء |
| Not bound | المشروع غير متصل |
| Not healthy | الموصل أو المزود غير جاهز |
