# القيود المعروفة

## حدود المستخدم

| الموضوع | الحد | ممارسة جيدة |
| --- | --- | --- |
| سجل المحادثة | قد يكون محليا في المتصفح | استخدام مستندات PM وسجل الذكاء الاصطناعي للتتبعية المشتركة |
| المشروع النشط | تعتمد الصفحات على المشروع | مراجعة الشريط العلوي |
| `All projects` | لا يمنح الوصول إلى كل المشاريع | التحقق من الوصول الفعلي |
| إجابة الوكيل | ليست مستندا نهائيا | المراجعة وإنشاء مستند PM إذا لزم الأمر |
| الثقة | ليست موافقة | مراجعة الأدلة والحداثة |

## التكاملات

ليس كل موصل ظاهر قابلا للاستخدام دائما. يجب أن تكون تعريف المنصة وbinding المشروع والسياسة والدور والصحة وlive mode جاهزة إذا انطبق ذلك.

## إدارة Azure

لا يثبت المزود المختار عند النشر المزود المستخدم بواسطة run. يقوم **Refresh Marketplace plan** بمزامنة المعلومات فقط.
