# الوكلاء

يعمل الوكلاء ضمن سياق المشروع النشط ويمكنهم إنتاج مخرجات منظمة مع أدلة.

## الوكلاء القياسيون

| الحاجة | الوكيل |
| --- | --- |
| تحليل شامل | Orchestrator |
| السياسات والموافقات | Governance |
| النطاق والمتطلبات | Scope |
| التخطيط والاعتماديات | Schedule |
| الميزانية والتكاليف | Finance |
| أصحاب المصلحة والتواصل | Stakeholders |
| السعة والموارد | Resources |
| المخاطر والمشكلات | Risk |

## تشغيل run

1. افتح **الوكلاء**.
2. تحقق من المشروع النشط.
3. حدد الوكيل.
4. اكتب طلبا دقيقا يتضمن الهدف والسياق.
5. أضف مستندات إذا كانت الواجهة تسمح بذلك.
6. ابدأ run.
7. اقرأ الرد، والاستشهادات، والحداثة، والثقة.
8. افتح [سجل الذكاء الاصطناعي](./journal-ia.md) إذا كنت تحتاج إلى التدقيق.

## الوكلاء المخصصون

أنشئ وكيلا مخصصا فقط بالدور المناسب. حدد الاسم، والغرض، ونطاق المشروع أو `All projects`، واحفظه واختبره بطلب بسيط.

## ملاحظات

لا يصبح رد الوكيل تلقائيا مستند PM نهائيا. يمكن أن يكون سجل المحادثة محليا في المتصفح.
