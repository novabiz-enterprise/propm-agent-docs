## Goal

This page explains how to add project knowledge, verify indexing, import from an approved source and read search results with citations.

## Upload a document

1. Open **Knowledge**.
2. Select **Upload**.
3. Choose the file.
4. Enter the category or metadata requested by the UI.
5. Start the upload.
6. Verify that the document appears in the list.
7. Wait for **Indexed** before using it as evidence.

## Import from an approved source

1. Open **Knowledge**.
2. Select the import action if available.
3. Choose the approved source.
4. Select the scope proposed by the UI.
5. Start the import.
6. Open import history to review imported, skipped and failed items.

## Statuses

| Status | Meaning | Action |
| --- | --- | --- |
| Indexed | Ready for search and agents | Use the document |
| Ingesting | Processing is still running | Wait and refresh |
| Failed | Processing failed | Check format/source and contact support if needed |
| Not visible | Wrong project, filter or permission | Check active project and filters |

## Search evidence

1. Open **Knowledge**.
2. Enter a business term, question or document identifier.
3. Filter by category, source or freshness if available.
4. Open a relevant result.
5. Read snippet, citation, score, source label and source system when shown.
