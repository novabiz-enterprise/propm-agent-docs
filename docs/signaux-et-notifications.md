## Goal

This page explains how to handle operational signals and notifications without confusing alerts, drafts, digests and governed actions.

## Read a signal

1. Open **Signals**, **Inbox** or the signal area in **Workspace**.
2. Check severity, status, mode and date.
3. Open the signal details.
4. Read evidence, sources and recommendations.
5. Decide whether to handle, snooze, dismiss, draft or escalate.

## Common actions

| Action | Effect |
| --- | --- |
| Refresh | Reloads or recalculates visible signals |
| Generate digest draft | Prepares a summary digest |
| Create draft | Creates a usable draft |
| Snooze 24h | Temporarily delays the signal |
| Dismiss | Closes the signal |

## Notification center

1. Open the notification icon in the top bar.
2. Select a notification to open the linked page.
3. Use **Mark all read** if available.
4. Use **Clear** only when the local list is no longer needed.
