## Goal

This page explains how to select the active project, create a project and verify that Knowledge, Agents, PM Documents and AI Log use the right context.

## Select an active project

1. Open the project switcher in the top bar.
2. Search for the project if the list is long.
3. Select the project.
4. Confirm that the project name appears in the top bar.
5. Open **Dashboard** or **Workspace** to confirm the data matches.

## Create a project

1. Open **Projects**.
2. Select **Create project** if the button is available.
3. Enter name, description and required settings.
4. Choose the default data language if shown.
5. Add additional languages only when the project sources need them.
6. Save the project.
7. Confirm that it can be selected as the active project.

## Key concepts

| Concept | Meaning |
| --- | --- |
| Active project | Current operational context for project pages |
| All projects | Scope limited to projects the same account can already access |
| Locally remembered project | Browser-local preference that may differ across devices |

## Common issues

| Symptom | Likely cause | Recommended action |
| --- | --- | --- |
| Create button missing | Insufficient role | Ask for the required role |
| Project not visible | You are not a project member | Ask the Project Owner |
| Pages stay empty | No active project | Select the project in the top bar |
| Data does not match | Wrong active project | Switch project and reload |
