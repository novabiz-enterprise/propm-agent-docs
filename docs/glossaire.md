## Label convention

This glossary uses the business term first and keeps the exact UI label when it avoids ambiguity. Terms marked **support/admin** are not required for daily end-user work.

## Key terms

| Term | Definition |
| --- | --- |
| Active project | Current context for Dashboard, Knowledge, Agents, PM Documents, Signals, Actions and AI Log |
| Add to knowledge | Adds a reviewed PM Document back into project knowledge |
| Agent | Specialized assistant working in active project context |
| All projects | Scope limited to projects the same account can already access |
| Artifact | Governed object from a run or review |
| Cohort | Saved Portfolio comparison configuration |
| Confidence | Signal of output solidity, read with evidence and freshness |
| Context snapshot | **Support/admin** context captured for a run |
| Diff | Comparison between artifact or PM Document versions |
| Document PM / PM Doc | Reviewed, versioned and governed project deliverable |
| Download | Creates a local copy |
| Effective AI Provider | Provider actually used by a run, visible in AI Log |
| Entitlement | **Support/admin** operational blocker, not a Marketplace feature tier |
| Evidence gap | Missing or insufficient evidence |
| Freshness | Evidence state: `fresh`, `aging`, `stale`, `conflicting`, `unavailable` |
| Lineage | Traceability chain from run to PM Document and evidence |
| Portfolio | Multi-project comparison surface |
| Project binding | Link that makes a platform integration usable in a project |
| Publish | Sends a deliverable to a governed destination |
| Refresh Marketplace plan | Admin sync action; it does not buy licenses or change plan |
| Run | Recorded AI or agent execution |
| Seat | User license unit |
| Structured output | Formatted run result with summary, evidence and actions |
| Trace ID | **Support/admin** correlation identifier |
| Validate | Admin consistency check before test or activation |
