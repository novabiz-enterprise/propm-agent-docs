## Goal

This page explains how to choose an agent, run it, understand local sessions and create a custom agent when your role allows it.

## Standard agents

| Need | Agent |
| --- | --- |
| Cross-functional analysis | Orchestrator |
| Decisions, policies or approvals | Governance |
| Scope, deliverables and requirements | Scope |
| Schedule, milestones and dependencies | Schedule |
| Budget, cost and variance | Finance |
| Communication and stakeholders | Stakeholders |
| Capacity and resources | Resources |
| Risks, issues and responses | Risk |

## Run an agent

1. Open **Agents**.
2. Verify the active project.
3. Select the agent.
4. Write a precise prompt with objective, context and expected format.
5. Attach or reference documents if the UI supports it.
6. Start the run.
7. Read the answer, citations, freshness and confidence.
8. Open **AI Log** if you need to audit the execution.

## Custom agents

1. Open **Agents**.
2. Select the custom-agent creation action if available.
3. Name the agent and describe its business purpose.
4. Choose project scope or **All projects** when allowed.
5. Save and run a simple test.
6. Delete or disable the agent when it should no longer be used.

## Important notes

- An agent response is not automatically a final PM Document.
- Browser-local chat sessions are not a central shared archive.
- Voice input is a convenience feature and depends on the browser.
